Xuất Dữ Liệu Sao Lưu

Tải toàn bộ danh sách tài khoản, lịch sử giá và trạng thái thành file JSON sao lưu an toàn. Dễ dàng chuyển sang máy tính khác hoặc lưu trữ đề phòng rủi ro.

Khôi Phục Dữ Liệu

Chọn tệp tin JSON đã sao lưu trước đó để khôi phục toàn bộ kho tài khoản. Lưu ý: Thao tác này sẽ ghi đè lên kho dữ liệu hiện tại.
